## 🔧 Что нужно сделать дальше

### 1. Настроить базу данных PostgreSQL

Убедитесь, что у вас установлен и запущен PostgreSQL, затем:

1. Создайте базу данных:
```bash
createdb looklike
```

2. Обновите `.env.local` с правильными данными подключения:
```env
DATABASE_URL="postgresql://username:password@localhost:5432/looklike"
```

3. Примените схему базы данных:
```bash
npx prisma db push
```

### 2. Настроить аутентификацию (опционально для MVP)

Для админ панели можно временно отключить аутентификацию или настроить NextAuth.js.

### 3. Тестирование

1. Откройте http://localhost:3000
2. Перейдите в `/admin` и создайте новый Review Set
3. Добавьте изображения (можно использовать URL из Picsum или любые другие)
4. Сгенерируйте ссылку для клиента
5. Откройте ссылку `/r/[token]` и протестируйте swipe-интерфейс

## 📝 Структура проекта

```
/app
  /admin          - Админ панель
  /api            - API endpoints
  /r/[token]      - Клиентский swipe-интерфейс
/components       - React компоненты
/lib              - Утилиты (Prisma client)
/prisma           - Prisma схема
```

## 🚀 Деплой

Для деплоя на Vercel:

1. Подключите репозиторий к Vercel
2. Настройте переменные окружения в Vercel dashboard
3. Настройте PostgreSQL (Supabase, Neon, или Railway)
4. Деплой произойдет автоматически
