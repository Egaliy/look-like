## ✅ ШАГ 4: Настройка переменных окружения

### 4.1. Создать файл `.env` на сервере со следующими переменными:

```env
# База данных (заменить на реальный connection string)
DATABASE_URL="postgresql://user:password@host:5432/dbname?sslmode=require"

# NextAuth.js
NEXTAUTH_URL="https://yourdomain.com"
NEXTAUTH_SECRET="сгенерировать-случайную-строку-минимум-32-символа"

# Опционально: S3 хранилище для изображений
S3_ENDPOINT=""
S3_ACCESS_KEY_ID=""
S3_SECRET_ACCESS_KEY=""
S3_BUCKET_NAME=""
S3_REGION=""

# Node окружение
NODE_ENV="production"
```

### 4.2. Сгенерировать NEXTAUTH_SECRET
```bash
openssl rand -base64 32
```

## ✅ ШАГ 5: Выбор платформы для деплоя

### Вариант A: Vercel (рекомендуется для Next.js)

**Преимущества:**
- Автоматический деплой из Git
- Бесплатный план для старта
- Встроенная поддержка Next.js
- Автоматический SSL

**Шаги:**
1. [ ] Зарегистрироваться на https://vercel.com
2. [ ] Подключить GitHub репозиторий
3. [ ] Настроить переменные окружения в Vercel Dashboard
4. [ ] Добавить DATABASE_URL в Environment Variables
5. [ ] Добавить NEXTAUTH_URL и NEXTAUTH_SECRET
6. [ ] Задеплоить проект

**Команды:**
```bash
npm i -g vercel
vercel login
vercel --prod
```

### Вариант B: Railway

**Преимущества:**
- Простая настройка
- Встроенная поддержка PostgreSQL
- Автоматический деплой

**Шаги:**
1. [ ] Зарегистрироваться на https://railway.app
2. [ ] Создать новый проект из GitHub
3. [ ] Добавить PostgreSQL сервис
4. [ ] Настроить переменные окружения
5. [ ] Задеплоить

### Вариант C: Собственный VPS (DigitalOcean, Hetzner, etc.)

**Требования:**
- VPS с Ubuntu/Debian
- Node.js 18+ установлен
- PostgreSQL установлен
- Nginx для reverse proxy
- PM2 для управления процессом

**Шаги:**
1. [ ] Подключиться к серверу по SSH
2. [ ] Установить Node.js и PostgreSQL
3. [ ] Клонировать репозиторий
4. [ ] Установить зависимости: `npm install --production`
5. [ ] Настроить `.env` файл
6. [ ] Запустить `npx prisma generate && npx prisma db push`
7. [ ] Собрать проект: `npm run build`
8. [ ] Настроить PM2: `pm2 start npm --name "look-like" -- start`
9. [ ] Настроить Nginx как reverse proxy
10. [ ] Настроить SSL через Let's Encrypt

```bash

sudo certbot --nginx -d yourdomain.com
```
